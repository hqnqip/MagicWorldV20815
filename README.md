# Magic 101
## Advanced Java with Android Studios
### 08/23/2024
### Assignment Description
The assignment requires me to create a text-based program that uses user-input to make decisions. The setting is a fantasy world where bards, wizards, and elves co-exist. The player takes the role of a traveler. The game begins with asking the player which class they want to be: Bard, Wizard, or Elf. Then, the game continues with the story until the player encounters two goblins. Based on the class the player selected, the player has access to different actions and has different character stats, such as health-points, attack, defense, etc. Likewise, the goblins also have their own unique stats, and they can attack or defend.

### Rubric
#### • Driver / Main Class
Two objects must be created for each object class, paired with calling their respective getters, setters, and brain methods. An ArrayList should be created with those objects.
#### • Object Classes
All classes– whether parent or child– must have at least two constructors, getters, setters, and a toString() method. However, each child class must have their own unique attributes and brain methods.

### How to Use
Run the program on IntelliJ.
The game is introduced. You are asked to type a username; otherwise, you are registered as a guest.
Then, the program introduces your rival, someone to play against you. 

Both you and your rival begin on Position 1. 
Answer the prompt or question assigned to that position.
Answer correctly, you have a chance to make the basketball hoop and advance.
Answer incorrectly, you automatically return to Position 1.

The goal is for you to make your way to Position 7, OR be the first person to earn 30 points by making in hoops.
Each position number you are on will give you that number of points. Ex. Position 4 --> 4 points.
