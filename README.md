# Magic 101
## Advanced Java with Android Studios
#### 08/23/2024
This is a text-based program that uses user-input to make decisions. The setting is a fantasy world where bards, wizards, and elves co-exist. The player takes the role of a traveler. The game begins with asking the player which class they want to be: Bard, Wizard, or Elf. Then, the game continues with the story until the player encounters two goblins. Based on the class the player selected, the player has access to different actions and has different character stats, such as health-points, attack, defense, etc. Likewise, the goblins also have their own unique stats, and they can attack or defend.

The spells casted by the Wizard type are ideas credited to Jorge Toribio.

Developed through IntelliJ.
